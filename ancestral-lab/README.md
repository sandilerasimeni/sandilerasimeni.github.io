# Lineage Lab

A static, browser-based educational prototype exploring how CNN face detection and seeded stochastic variation can support a **fictional portrait illustration**. It is not an ancestry, identity, DNA, or genetic prediction tool.

## Run locally

No build step or API key is required. From the repository root, serve the files with any static web server, then open `/ancestral-lab/`:

```bash
python -m http.server 8000
```

Open <http://localhost:8000/ancestral-lab/>. You can also open `ancestral-lab/index.html` directly in a modern browser, though serving over localhost is recommended. The CNN scripts and pretrained detector weights load from jsDelivr, so internet access is needed for face detection.

## Demo

1. Select a JPG, PNG, or WebP image up to 8 MB containing one clearly visible face.
2. Choose a generation depth from 1 to 50 and a simulation seed.
3. Run **Explore imagined paths** to generate four deterministic fictional illustrations for that seed and depth.

The selected image is decoded and analyzed locally in the browser. The app does not upload, persist, or transmit the image. Remove it with the button under the preview.

## What is actually implemented

- **CNN:** TensorFlow.js with the pretrained BlazeFace convolutional face detector. It locates a face and landmarks in the browser.
- **Illustration input:** A few coarse, non-identifying geometric measurements initialize a small parameter vector. The app does not infer ethnicity, identity, kinship, or ancestry.
- **Generation:** A seeded stochastic random walk perturbs that vector over the chosen number of steps. A small inline SVG renderer draws abstract portrait illustrations.

## VAE status and limitations

This version does **not** contain a trained variational autoencoder (VAE), a face-generating CNN decoder, or a biological inheritance model. The illustrated outputs are not generated by a neural decoder. A meaningful VAE would require an appropriately licensed and representative dataset, a documented training/evaluation pipeline, and a trained model artifact; a single uploaded photograph cannot provide that training data or reveal 50 generations of ancestors. Calling this prototype a VAE or an ancestor predictor would be misleading.

A future research stage could evaluate a properly licensed pretrained generative model for clearly fictional portrait exploration. It should keep the same explicit limitations and privacy safeguards, and should not represent outputs as real relatives.

## Stack

- HTML, CSS, vanilla JavaScript
- TensorFlow.js 4.x
- TensorFlow.js BlazeFace model
- Canvas API and inline SVG

## Privacy and safety

All image processing is client-side. The external TensorFlow.js library and detector weights are fetched from jsDelivr; the image itself is not sent to that CDN or any app backend. Do not upload images without the subject's permission.
